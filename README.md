# Pixel Xpress Help

Pixel Xpress is a small color display for model trains and layouts. It shows your own pictures and
slideshows, and you set it up and change its pictures from the **Pixel Xpress** phone app.

**Website version of this help:** https://customrailcreations.github.io/PixelXpressDocumentation/

---

## Start here

1. **[Getting started](docs/getting-started.md)**: set up a new display with the phone app (5 minutes).
2. **[Using the mobile app](docs/mobile-app.md)**: upload pictures, make slideshows, manage displays.
3. **[Display buttons](docs/display-buttons.md)**: what the A, B, X and Y buttons do.

## Quick answers

| Question | Answer |
|---|---|
| Which Wi-Fi does it need? | A **2.4 GHz** network (most home routers have one). 5 GHz-only networks don't work. |
| How many pictures? | Up to **7** per slideshow. |
| Display won't start? | Unplug it for 10 seconds. Still stuck? Use the [Pixel Xpress Flasher](docs/repair-with-flasher.md); your pictures and Wi-Fi settings are kept. |
| Moving the display to a new Wi-Fi? | Hold **Y** on the display for 5 seconds, then add it again in the app. [Details](docs/mobile-app.md#change-wi-fi-details) |
