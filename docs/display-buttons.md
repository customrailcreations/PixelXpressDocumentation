# Display buttons

[← All guides](../README.md)

The display has four buttons beside the screen, labeled **A**, **B**, **X** and **Y**.

| Button | What it does |
|---|---|
| **A** | Previous picture |
| **B** | Next picture |
| **X** | Pause the slideshow, or resume it. While paused, the current picture stays on screen |
| **Y** | Shows an **info screen** for 10 seconds (see below) |
| **Y, held for 5 seconds** | **Forget Wi-Fi**: the display shows "Forgetting Wi-Fi…" and restarts in Bluetooth setup mode, ready to be added again in the app |
| **A, held while plugging in the power** | **Safe mode**: the display shows "SAFE MODE" and doesn't start its app. Only needed for repairs; unplug and plug in again (without holding A) to start normally |

## The info screen (button Y)

| Line | Meaning |
|---|---|
| Pixel Xpress *version* | The display's software version |
| Name | The display's Bluetooth/network name (starts with **pxe**) |
| IP | Its address on your Wi-Fi, or "not connected" |
| Storage free | Space left for pictures |
| Memory free | Working memory (for support) |
| Hold Y 5 s: reset Wi-Fi | Reminder of how to forget the Wi-Fi |

The picture comes back by itself after 10 seconds, or straight away if you press A or B.

## The update button

There is also a small **update button** on the display's circuit board (not one of A, B, X, Y). It's
only used to repair a display. See [Repairing a display with the Pixel Xpress Flasher](repair-with-flasher.md).
