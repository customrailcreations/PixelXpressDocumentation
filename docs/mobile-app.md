# Using the mobile app

[← All guides](../README.md)

## Main screen

The main screen lists your displays. Each one shows its name, MAC address, IP address and
software version. The icon on the right shows its status:

| Icon | Meaning |
|---|---|
| Spinning circle | Checking the display |
| Green upload arrow | Online. Tap it to upload pictures |
| Red crossed-out Wi-Fi | Offline: powered off, out of Wi-Fi range, or not connected yet |

**Update available** next to a display means the app has newer software for it. See
[Updating over Wi-Fi](update-over-wifi.md).

The buttons at the top of every screen:

| Button | What it does |
|---|---|
| **Shop** | Opens the Custom Rail Creations store in your web browser |
| **Support** | Opens these guides in your web browser |
| ⚙ (gear) | **Settings**: the Wi-Fi name and password the app gives new displays |

The **Scan Devices** button at the bottom adds a new display. See
[Getting started](getting-started.md).

## Display actions

Tap a display's name to open its actions:

| Action | What it does |
|---|---|
| **Upload Image or Slideshow** | Choose new pictures for the display (see below) |
| **Update Software** | Shows the display's software version and installs updates. See [Updating over Wi-Fi](update-over-wifi.md) |
| **Reboot Device** | Restarts the display. It reconnects by itself and the app waits for it |
| **Delete Device** | Removes the display from the app. It keeps its pictures and Wi-Fi; you can add it again with **Scan Devices** |

## Upload pictures or a slideshow

1. Tap the display's **green upload icon**, or open the display and tap **Upload Image or Slideshow**.
2. The app checks how much space the display has.
3. On **Creating Slideshow for …**:
   - Tap **Add Image**, pick a photo, and crop it. The crop box matches the display's shape.
   - Add more pictures the same way, up to **7**. The numbers show the order they're shown in.
     Remove a picture with its delete button.
   - **Image Delay (seconds)** sets how long each picture stays on screen (15 seconds to start with).
4. Tap **Upload**. The app sends each picture, then the display restarts and shows your new
   slideshow.

One picture makes a still display; two or more make a slideshow. A new upload replaces the
pictures already on the display.

Messages you might see:
- **Maximum Storage Space**: you've added as many pictures as fit. Remove one to add another.
- **Insufficient Disk Space**: the display can't fit this slideshow. Try fewer pictures.
- **Device Disconnected**: the app can't reach the display. See
  [Troubleshooting](troubleshooting.md#the-app-says-device-disconnected-or-shows-a-red-wi-fi-icon).

## Change Wi-Fi details

Tap ⚙ **Settings**, enter the new **Wi-Fi SSID** and **Wi-Fi Password**, and tap **Save**. This
is used for displays you add from now on. To move an existing display to a new network:

1. On the display, **hold the Y button for 5 seconds**. It forgets its Wi-Fi and restarts in setup
   mode. See [Display buttons](display-buttons.md).
2. In the app, delete the display (**Delete Device**), then add it again with **Scan Devices**.
