# Updating the device software over Wi-Fi

[← All guides](../README.md)

New versions of the Pixel Xpress phone app can include newer software for your displays. Your
phone installs it over Wi-Fi; no cable or computer is needed.

## Install an update

1. Update the **Pixel Xpress** app from the App Store or Google Play.
2. Open the app. Displays that can be updated show **Update available** on the main screen.
3. Tap the display, then **Update Software**.
4. Keep the phone on the same Wi-Fi and leave the display powered. The app sends the update, and
   the display restarts once or twice. This takes about a minute.
5. When it's done, the app shows **Display updated** and the new version number.

Your pictures and Wi-Fi settings are kept.

## If an update doesn't work

The display checks every update before using it and only accepts genuine Pixel Xpress updates.
If a new version can't start properly three times, the display **goes back to its previous
software by itself**, and the app tells you. Nothing is lost, and the display keeps working.

| Message | What to do |
|---|---|
| *This display already has this version or newer* | Nothing; it's up to date |
| *…needs new firmware before it can be updated over Wi-Fi* | Update it once with the [Pixel Xpress Flasher](repair-with-flasher.md) on a computer; after that, Wi-Fi updates work |
| *…didn't work on this display before…* | The display already tried this version and went back. Contact support |
| *The display rejected the update file* | Update the phone app and try again; contact support if it continues |
| *The update didn't finish* | Check the display is on and in Wi-Fi range, then try again |

## Wi-Fi updates or the Flasher?

- **Wi-Fi updates (phone app):** for normal updates. Quick and easy.
- **[Pixel Xpress Flasher](repair-with-flasher.md) (computer + USB cable):** when the display won't
  start, or when support asks you to reinstall its software. It installs all of the display's
  software in one go.
